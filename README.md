# go-didweb

Package **didweb** provides an implementation of DID-Web (did:web), for the Go programming language.

Note that a sub-set of DID-Web (did:web) is used by AT-Protocol (ATProto).

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-didweb

[![GoDoc](https://godoc.org/github.com/reiver/go-didweb?status.svg)](https://godoc.org/github.com/reiver/go-didweb)

## Import

To import package **didweb** use `import` code like the following:

```
import "github.com/reiver/go-didweb"
```

## Installation

To install package **didweb** do the following:

```
GOPROXY=direct go get https://github.com/reiver/go-didweb
```
